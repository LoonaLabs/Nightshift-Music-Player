🌙 Nightshift Music Player

A modern dark-themed music player built with pure HTML, CSS and JavaScript, with no framework and no backend. Pick a genre, hit play, and enjoy.

🔗 Live demo: https://loonalabs.github.io/Nightshift-Music-Player/

Nightshift Music Player screenshot

✨ Features

   🎵 Play / pause, next and previous track
   🔀 Shuffle and 🔁 repeat modes
   🔊 Volume control
   ❤️ Favorite tracks
   ⬇️ Download button and ▶️ YouTube link
   🖼️ Cover art for every track
   🎧 6 genres: Metal, Moroccan Rap, Raï, Electronic, Blues, Orchestral
   🌑 Dark, modern and responsive UI

🛠️ Tech Stack

Technology	                          Usage

HTML5	                                Structure and <audio> element
CSS3	                                Dark theme, layout, responsive design
JavaScript (ES6)	                    Player logic, playlist, controls
GitHub Pages	                        Hosting

🚀 Run Locally 

# 1. Clone the repository
git clone https://github.com/LoonaLabs/Nightshift-Music-Player.git

# 2. Go into the project folder
cd Nightshift-Music-Player

# 3. Open index.html in your browser
#    (or use the Live Server extension in VS Code)
